Set Pam up

Two services need a key of your own. Add them here and Pam starts using them straight away — no file editing, no restart. Everything stays on this laptop.

Google Calendar

Checking…

Read-only: Pam reads today's events and never changes your calendar.

  1. In Google Cloud, enable the Google Calendar API.
  2. On the consent screen, add your own Google account as a test user.
  3. Create credentials → OAuth client ID → Web application, with this redirect URI:
    http://127.0.0.1:8000/api/calendar/google/callback
  4. Paste the client ID and secret below. Google's approval page opens by itself.

Flight search

Checking…

Google publishes no flights API of its own, so Pam reads Google Flights results through SerpApi. The free plan allows 250 searches a month and needs no card. Pam never books or pays for anything.

  1. Create a free account at serpapi.com.
  2. Copy your private API key from the dashboard and paste it below.

Keys are written to server/.env, which is gitignored and readable only by your Windows account. Pam never shows a saved key again, and never sends one to the phone.
